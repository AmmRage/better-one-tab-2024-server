# Another One Tab 2026 2024 扩展

Chrome 浏览器扩展，用于保存和管理浏览器标签，支持多设备同步。

## 功能特性

1. **右键菜单功能**
   - 保存并保存当前标签
   - 保存并关闭当前窗口所有标签
   - 保存并关闭所有窗口标签

2. **标签管理**
   - 按保存时间分组显示所有标签
   - 分组默认折叠，点击展开查看标签
   - 支持删除分组和单个标签
   - 支持双击编辑分组标题

3. **服务器同步**
   - 登录服务器
   - 上传所有分组到服务器
   - 从服务器下载并覆盖本地分组

## 安装说明

1. 打开 Chrome 浏览器，进入扩展管理页面：`chrome://extensions/`
2. 开启"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择 `extension` 目录

## 图标文件

扩展需要以下图标文件（需要自行添加）：
- `icon16.png` (16x16)
- `icon48.png` (48x48)
- `icon128.png` (128x128)

如果没有图标文件，可以创建简单的占位图标，或者从网上下载合适的图标。

## 使用说明

1. **保存标签**：在任意网页右键，选择相应的保存选项
2. **查看标签**：点击扩展图标，打开弹窗查看所有保存的标签
3. **登录服务器**：点击"登录"按钮，输入服务器地址、用户名和密码
4. **同步数据**：登录后可以使用"上传"和"下载"功能同步数据

## 服务器配置

默认服务器地址格式：`http://localhost:9401`

确保服务器已启动并可以访问。

## 技术栈

- Manifest V3
- 原生 JavaScript（不使用 TypeScript）
- 原生 HTML + CSS（不使用 UI 框架）
- Chrome Storage API
- Chrome Tabs API
- Chrome Context Menus API
