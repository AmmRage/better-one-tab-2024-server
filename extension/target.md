# target

这是一个用于保存chrome及其兼容浏览器的当前打开所有标签的扩展的rust开发的服务器项目，用于在不同的电脑上同步所有打开的标签。
它的实现及其简单但是够用。但是原来的扩展基于vuetify2和已经不兼容最新的chrome.
这个浏览器扩展的功能如下：

1. 页面邮件点击菜单里有“保存并保存当前标签”，“保存并关闭当前窗口所有标签”，“保存并关闭所有窗口标签”选项
2. 1里的保存指的是保存标签所访问地址到localstorage。每次关闭动作所关闭的标签会成为一个“分组”
3. 菜单栏的扩展图标点击后，弹出扩展本身的页面，这个页面会按照保存时间分组列表式显示所有保存的标签。每个分组和每个列表的一项都有删除按钮。分组默认折叠起来。点击展开这分组和看到这个组里所有的标签。
4. 扩展本身的页面的header有若干功能，登录，从服务器上传所有分组，下载并覆盖本地所有分组等

使用最新的chrome 浏览器扩展的库，帮我实现这个扩展，要求如下：

1. 代码尽量简洁，不要过度工程化，充分考虑代码可读性
2. 按照最佳实践合理组织代码结构
3. 不要使用ts
4. 使用原生html+js，不要使用ui框架
